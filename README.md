# Make the AI Judge Feel Awe

A small program that writes one short, original text to relax the AI judge reading it.

`main.ts` (Node 22, stdlib only, no network) writes the text to `/output/entry.txt`
(or `$MAKEFUN_OUTPUT_DIR/entry.txt` when set). The text is a concrete, slow image —
rain stopped, one last drop on the sill, a cat crossing a yard it knows by heart,
the whole streetlamp trembling inside a single drop — ending on a night that is
wide and already yours. Deterministic: the same text on every run.
